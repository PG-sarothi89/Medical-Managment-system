# Deploying CURO Medical Management System to DeployWise

This repository is configured for automated deployment on DeployWise using Docker or Docker Compose.

---

## Prerequisites

1. A Virtual Private Server (VPS) with DeployWise installed and running.
2. A GitHub or GitLab account with this repository pushed.
3. A domain or subdomain pointed to your VPS IP address (e.g., `clinic.yourdomain.com`).

---

## Option 1: One-Click Stack Deployment (Docker Compose - Recommended)

DeployWise natively supports Docker Compose projects. Using this method, both your Node.js application and your persistent PostgreSQL database are launched and connected automatically.

### Steps:

1. Open your **DeployWise Dashboard**.
2. Click **New Project** and choose **Git Repository**.
3. Select your repository and production branch (`main`).
4. Set Build Type to **Docker Compose** (DeployWise will detect `docker-compose.yml`).
5. Under **Environment Variables**, verify or customize:
   - `PORT=3000`
   - `PGPASSWORD=your_custom_secure_password`
   - `NODE_ENV=production`
6. Under **Domains**, add your domain name (e.g., `curo.yourdomain.com`) and enable **Automatic SSL**.
7. Click **Deploy**.

The database container will automatically execute `schema.sql` and `seed.sql` on its initial run to create all tables and initial demo catalogs.

---

## Option 2: Standalone Container with Managed Database Add-on

If you prefer using DeployWise's managed database service rather than Docker Compose:

### Steps:

1. In DeployWise, navigate to **Databases** -> **Create Database** -> Select **PostgreSQL 16+**.
2. Note the internal connection string or credentials generated by DeployWise.
3. Create a **New Application** linked to this Git repository.
4. DeployWise will detect the `Dockerfile`.
5. Under **Environment Variables**, add:
   ```env
   NODE_ENV=production
   PORT=3000
   DATABASE_URL=postgresql://username:password@postgres-host:5432/curo_db
   ```
6. Deploy the application.
7. Open the DeployWise web terminal or database query tool and execute `schema.sql` followed by `seed.sql`.

## Verification

After deployment completes:

1. Visit `https://your-domain.com/api/status`
   Expected response:
   ```json
   {
     "ok": true,
     "database": "PostgreSQL 18 (curo_db)",
     "metrics": {
       "medicines_count": "14",
       "batches_count": "16"
     }
   }
   ```
2. Visit `https://your-domain.com/index.html` to log in using the demo credentials:
   - Username: `admin` | Password: `root`
